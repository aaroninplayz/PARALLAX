    Introduction

Modern defence and surveillance systems rely heavily on direct detection methods—visual cameras, thermal imaging, or RF monitoring. However, adversaries increasingly use camouflage, stealth materials, and environmental blending techniques to avoid detection.
Traditional systems fail because they ask:
“Can I see the object?”
Project PARALLAX changes the question to:
“Is something present that statistically should not be there?”
This shift—from object detection to anomaly inference—is the foundation of the system.

    Core Concept

PARALLAX is based on a simple but powerful principle:
Hidden objects disturb the environment—even if they are not visible.
These disturbances can appear as:
Slight temperature inconsistencies Subtle visual texture disruptions Minor RF signal irregularities
Individually, these signals may be insignificant. But when combined and analyzed using AI, they form a detectable anomaly pattern.

    System Overview

PARALLAX is a multi-layered embedded AI system consisting of:
Layer 1: Sensor Acquisition Visual Camera (RGB) Thermal Sensor (Infrared) RF Sensor (signal disturbance detection) Layer 2: Preprocessing Noise filtering Normalization Frame synchronization Layer 3: Feature Extraction Extract meaningful patterns from each sensor stream Layer 4: AI-Based Anomaly Detection Learn “normal environment behavior” Detect deviations Layer 5: Sensor Fusion Engine Combine outputs from all sensors Increase reliability Layer 6: Output Interface Heatmaps Alerts Probability scores 4. Detect heat distribution inconsistencies.
Key Idea
Even when camouflaged, objects:
Emit heat Absorb heat differently Techniques Temperature gradient mapping Temporal heat variation tracking Thermal anomaly clustering 4.3 RF Sensing Module Purpose
Detect disturbances in radio frequency signals.
Concept
Objects affect RF signals via:
Reflection Absorption Diffraction Techniques Signal strength variation tracking (RSSI) Frequency spectrum analysis Noise pattern deviation 5. AI & Machine Learning Core 5.1 Why Anomaly Detection?
